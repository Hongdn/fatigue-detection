# 国内空管/航司疲劳监控竞品分析报告

> **版本**：v1.0
> **日期**：2026-07-13
> **范围**：中国大陆地区空中交通管制员（ATC）疲劳监控相关产品、项目、学术成果及航司 FRMS 系统
> **目的**：避免重复造轮子，识别差异化机会

---

## 一、调研概述

### 1.1 调研方法
- 公开网络检索（民航行业媒体、招投标平台、企业官网、专利数据库、学术数据库）
- 覆盖维度：已落地产品、在研项目、招投标信息、学术专利、行业标准

### 1.2 核心结论（先读这段）

1. **赛道已有先行者，但仍是早期市场**：西南空管局已采购中科昊音的系统并自研原型，甘肃分局已招标情绪识别系统。需求真实，但全国铺开尚早。
2. **最大直接竞品是中科昊音**：走"声纹+图像"路线，已被西南空管局采购，2025 年新申请的专利已认识到"个体基线对比"的必要性——与我们的核心思路撞车。
3. **语音路线学术积累深厚但产品化不足**：民航大学、民航飞行学院的论文准确率达 97%+，但均为实验室成果，未见成熟商用产品。这是机会，也是坑。
4. **标准已出，合规框架明确**：T/CATAGS106-2026《空中交通管制员岗位值勤工作状态量化评估指南》于 2026 年发布，给出了注意力/警觉度/情绪状态/身体机能四维评估框架，产品设计必须对齐。
5. **差异化空间**：纯语音轻量化方案、多信号融合闭环、与 FRMS 打通的产品存在缺口。但"语音判疲劳"这条路中科昊音已占位，需重新定位差异化。

## 二、市场格局总览

国内管制员疲劳监控市场可分为四类玩家：

| 类别 | 代表 | 特点 |
|------|------|------|
| **民企（声纹/AI）** | 中科昊音 | 技术驱动，走科研项目签约切入空管局 |
| **空管局下属单位** | 西南空管局网络公司 | 自研原型，区域内试用 |
| **科研院所** | 民航二所、航科院、电科28所 | 生理信号/FRMS路线，参与标准制定 |
| **空管大厂** | 川大智胜、莱斯信息、太极公司 | 渠道强，可能切入 |
| **高校** | 中国民航大学、中国民航飞行学院 | 学术研究，专利/论文积累 |

**市场阶段判断**：概念验证 → 早期试用阶段。全国 7 大地区空管局尚未规模化采购，是进入窗口期。

## 三、直接竞品详细分析

### 3.1 中科昊音（安徽中科昊音智能科技有限公司）⚠️ 最大威胁

**这是与我们方案最接近的直接竞品，必须重点研究。**

| 维度 | 信息 |
|------|------|
| **技术路线** | 声纹识别 + 图像识别（多模态） |
| **产品** | 空中交通管制员岗位疲劳状态监测告警系统 |
| **方案细节** | 现场图像采集（头部姿态、嘴部、眼睛特征）+ 声音采集→私有云声纹分析→疲劳检测；触发告警后推送管制主任手环 |
| **客户** | 民航西南空管局（已签约科研项目"多特征参数模糊融合判断方法监测分析管制员疲劳状态并自动检测告警技术研究"） |
| **专利1** | CN113327404A（2021年）岗位疲劳状态监测告警系统，发明人含西南空管局何天剑 |
| **专利2** | CN120340198A（2025年3月申请）基于声纹识别的空管疲劳监测系统及方法——**明确提出"构建个体基准声纹特征数据，与当前声纹对比"**，已认识到个体基线对比的必要性 |
| **融资** | 2019年千万级天使轮，2024年Pre-A轮（浚泉投资），计划A轮 |
| **客单价** | 数百万级 |
| **声纹识别准确率** | 号称 98%（电话声纹识别，非疲劳） |

**关键警示**：

- 已绑定西南空管局（何天剑局长是专利发明人），渠道壁垒高。

## 五、相关市场：航司 FRMS（飞行员，非管制员）

航司 FRMS 针对的是**飞行机组**，与管制员场景不同，但技术栈和合规框架可借鉴。

### 5.1 航科院（中国民航科学技术研究院）— FRMS平台

| 维度 | 信息 |
|------|------|
| **产品** | 疲劳风险管理平台（APP端+Web端） |
| **客户** | 国航、川航、海航、首都航等多家航司 |
| **技术** | 华为手表采集睡眠数据 + FAID模型计算疲劳风险 |
| **规模** | 超远程国际航班生物数据采集超20000人次，航班超147000班次 |

### 5.2 南航 + 中国民航大学 FRMS

| 维度 | 信息 |
|------|------|
| **时间** | 2022年12月局方批准，2023年6月验收 |
| **成果** | 自主知识产权警觉度测试（PVT）+ 疲劳预测生物数学模型 |
| **航线** | 北美、欧洲、大洋洲国际航线数据采集 |

### 5.3 川航 + 航科院 FRMS

| 维度 | 信息 |
|------|------|
| **时间** | 2021年12月启动 |
| **特点** | 国内首家自研生物数学模型 + 国产穿戴硬件（华为GT2手表） |
| **模型** | FAID模型 |

### 5.4 厦门航空 — 招募中

招募要求：PVT警觉度测评系统（含专利）+ 睡眠监测手环（续航20天+）+ 飞行疲劳数据分析系统（两过程/三过程生物数学模型）。

**FRMS 市场启示**：
- 飞行员 FRMS 已较成熟，但**管制员 FRMS 几乎空白**——管制员场景的疲劳监控产品稀缺。
- FAID 生物数学模型是行业事实标准，可考虑引入管制员场景。
- 华为手表已成为国产穿戴设备的事实选择。

## 六、学术研究成果（语音路线）

### 6.1 中国民航大学

| 成果 | 技术细节 | 准确率 |
|------|---------|--------|
| 专利：基于远程塔台场景的管制员语音疲劳预测方法（2025年） | 韵律+音质+语谱特征融合 → Bi-LSTM-GRU | - |
| 论文：基于深度学习的管制员语音疲劳检测（陈超） | 语谱图→ConvNeXt改进 D-AlstNet（CNN+LSTM+注意力） | 97.2% |
| 论文：管制员哈欠检测（王超等） | 视频→CNN+LSTM嘴部行为识别 | 较传统提升14.4% |
| 论文：语音疲劳特征提取（李兆悦，2020） | 韵律特征+音节级特征→kNN/SVM | 较传统提升20-55% |

### 6.2 中国民航飞行学院

| 成果 | 技术细节 | 准确率 |
|------|---------|--------|
| 论文：基于语谱图的管制员疲劳检测（2023） | 语谱图→ConvNeXt | 97.1% |
| 论文：管制员语音疲劳检测 | VGG16/ResNet34/ConvNeXt-T | 92.08%（ConvNeXt-T） |

**学术成果启示**：
- **自建语料库**：民航飞行学院陈超构建了管制员疲劳语音数据库（正常1510条+疲劳1506条），用工作时长+工作强度诱发疲劳，PVT反应时+疲劳量表标注。这是关键基础设施。
- **97% 准确率是在受控实验室**：真实电台环境会大幅下降，不可直接引用。
- **语谱图+ConvNeXt 是当前学术主流**，但工程上 openSMILE 特征更轻量、可解释。

## 七、标准与合规

### 7.1 T/CATAGS106-2026《空中交通管制员岗位值勤工作状态量化评估指南》

| 维度 | 内容 |
|------|------|
| **发布** | 中国航空运输协会，2026年 |
| **起草单位** | 电科28所、民航二所、四川大学、南京航空航天大学 |
| **适用** | 民用航空空中交通管制单位管制员岗位值勤工作状态量化评估 |
| **四维评估框架** | ①注意力 ②警觉度 ③情绪状态 ④身体机能 |
| **内容** | 明确四维度的评估指标、检测方法、分级标准、指标采集与数据处理要求 |

**合规要求**：产品设计必须对齐这四个维度，否则难以通过行业验收。

### 7.2 其他相关法规

- **ICAO Doc 9966**——疲劳风险管理国际框架
- **《个人信息保护法》**——声纹属生物特征，需单独同意

## 九、差异化机会与建议

### 9.1 已被占位的，不要重复造

| 已被占位 | 占位方 | 我们的应对 |
|---------|--------|-----------|
| 个体基线声纹对比 | 中科昊音(2025专利) | 不要作为核心卖点，要做就做更深（多特征+时序基线+班次基线） |
| 声纹+图像多模态 | 中科昊音 | 不要正面竞争多模态，找差异维度 |
| 视频疲劳检测(哈欠/闭眼) | 中科昊音、川大智胜、高校 | 已是红海，不建议自研 |
| FRMS生物数学模型 | 航科院、南航、民航大学 | 飞行员场景已成熟，管制员可借鉴FAID但非自研重点 |

### 9.2 差异化空间（建议聚焦）

1. **"语音为主"的轻量化方案**（vs 中科昊音"图像为主"）
   - 中科昊音依赖席位摄像头，部署重、隐私争议大
   - 纯语音方案只需接入已有通话录音，**部署成本极低**，这是核心差异点
   - 卖点："无需摄像头、不改席位、接通话线即用"

2. **多信号融合闭环**（vs 单一信号）
   - 现有产品多单一信号（图像 OR 声纹 OR 生理）
   - 我们做"语音疲劳分 + 值班时长 + 排班节律"融合，更接近真实疲劳
   - 重点：把 FAID 生物数学模型引入管制员场景（现有 FRMS 只用于飞行员）

3. **班次级个体基线**（vs 中科昊音的单一基准）
   - 中科昊音专利提到个体基准，但未区分班次
   - 管制员倒班制下，夜班/白班/早班的"正常"语音基线不同
   - 做"分班次个体基线"是可申请专利的差异点

4. **与空管排班系统打通**（vs 孤立监控）
   - 甘肃分局招标已显示"排班+情绪识别"组合需求
   - 把疲劳监控结果反馈到排班优化，形成闭环，是采购方更想要的形态

5. **对齐 T/CATAGS106-2026 四维标准**（vs 无标准对标）
   - 多数现有产品未对标新标准
   - 我们的语音方案可映射到"警觉度+情绪状态"两维，补"注意力+身体机能"用值班数据
   - 率先声明对标标准，是准入优势

### 9.3 不建议做的

- ❌ 自研视频疲劳检测（哈欠/闭眼）——红海，川大智胜+中科昊音已占位
- ❌ 自研穿戴设备——航科院+华为已固化，管制员接受度低
- ❌ 正面对标中科昊音的多模态方案——其已绑定西南空管局，正面竞争无优势
- ❌ 宣称"97%准确率"——学术数字，真实环境会暴跌，反而损害可信度

## 十、结论与下一步建议

### 10.1 市场判断

- 市场处于**早期试用阶段**，全国 7 大地区空管局尚未规模化采购
- **中科昊音已占位西南空管局**，但其方案偏重图像、部署重，留有差异化空间
- **T/CATAGS106-2026 标准发布**意味着行业正从"概念"走向"规范化"，是产品入场的窗口期

### 10.2 竞争策略建议

1. **避开中科昊音锋芒**：不自研图像疲劳检测，不打"多模态"牌
2. **主打"纯语音轻量化"**：差异化定位为"接通话线即用、无需摄像头、低部署成本"
3. **做"班次级个体基线"**：这是可专利的技术差异点，且贴合管制员倒班实际
4. **融合 FAID 模型 + 值班数据**：把航司 FRMS 的成熟方法平移到管制员场景
5. **对齐 T/CATAGS106-2026**：产品评估维度直接映射标准四维
6. **打包"排班+监控"**：参考甘肃分局招标，提供组合方案而非单一监控
