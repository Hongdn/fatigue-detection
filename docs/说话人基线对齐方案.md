# 说话人识别与聚类方案

> 版本：v2.0 | 日期：2026-07-27
> 定位：step0 声纹模块，接 step1 VAD 分段输出，为 step5 个体基线提供说话人分组

---

## 一、需求澄清

### 不是什么
- ❌ 说话人分离 (Diarization)：从连续音频中找"谁在什么时候说话"——这包含 VAD+分割+聚类，是端到端的
- ❌ 说话人验证 (Verification)：判断"这两段是不是同一个人"——是 1:1 比对

### 是什么
- ✅ **说话人嵌入提取 + 聚类**：输入已分好的 N 段语音 → 每段提取声纹向量 → 自动分组

```
step1 VAD 已切好的段
  │
  ▼
step0: 逐段提取 speaker embedding (192维)
  │
  ▼
step0: 余弦相似度聚类 → 自动分组
  │     段1,3,5 → speaker_0 (管制员)
  │     段2,4,6 → speaker_1 (飞行员)
  │
  ▼
step5: 每个说话人分别建个体基线
```

### 为什么不用 Diarization
1. VAD 分段已经在 step1 做完了，不需要重复
2. Diarization 是黑盒端到端，无法控制分段质量
3. 我们只需要 embedding + 聚类这一层，更灵活

## 二、模型选型

### 需求
- 输入：16kHz 单声道 WAV 段（0.3s ~ 10s）
- 输出：192 维 speaker embedding
- 多语言（中文 + 英文）
- 短语音表现好（管制通话通常 2-3 秒）
- 能直接 pip 安装使用

### 候选方案

| 方案 | EER | Stars | 安装 | 多语言 | 短语音 | 推荐 |
|------|:---:|:-----:|------|:------:|:------:|:----:|
| pyannote-audio | ~1.7% | 10.3k | pip | ✅ | 中 | ★ 最流行 |
| SpeechBrain ECAPA-TDNN | 0.87% | 11.7k | pip | ✅ | 中 | ⚠️ Windows兼容问题 |
| 3D-Speaker ERes2NetV2 | 0.61% | ~2k | pip+modelscope | ✅ | **最优** | ★ 准确+短语音最强 |
| WeSpeaker | 0.45% | 1.3k | git clone | ✅ | 中 | ⚠️ 安装麻烦 |

### 最终选型：3D-Speaker ERes2NetV2

理由：
1. **短语音最强**——3秒 EER 0.98%，2秒 EER 1.48%，管制通话就是这个长度
2. **pip 直装**——`pip install modelscope`，自动下载模型
3. **中文 20 万说话人预训练**——`iic/speech_eres2netv2_sv_zh-cn_16k-common`
4. **声纹特征语言无关**——虽然标注 zh-cn，但中英文都能用
5. **Apache 2.0 许可**——商用无限制

### 备选：pyannote-audio
如果 ERes2NetV2 安装有问题，fallback 到 pyannote-audio 的 embedding 提取：
```python
from pyannote.audio import Model
model = Model.from_pretrained("pyannote/embedding")
```

## 三、技术设计

### 3.1 模块结构

```
step0_voiceprint/
├── __init__.py
├── cluster.py          # SpeakerClusterer 类
│   ├── extract_embeddings()   # 逐段提取 192 维声纹
│   ├── cluster()              # 余弦相似度层次聚类
│   └── fit_predict()          # 端到端：提取+聚类 → 说话人ID列表
└── README.md
```

### 3.2 聚类算法

**贪婪层次聚类**（当前实现）：
1. 第一段 → 新建 speaker_0
2. 后续每段 → 计算与所有已有组的质心余弦相似度
3. 最高相似度 > 阈值(0.55) → 归入该组，更新质心
4. 否则 → 新建一组

优点：简单、在线增量、不需要预设说话人数量

**可选升级：HDBSCAN**
- 无需预设阈值
- 自动发现说话人数量
- 但需要安装 hdbscan 库

### 3.3 阈值选择

| 阈值 | 效果 | 适用场景 |
|------|------|---------|
| 0.40 | 宽松，容易合并不同人 | 说话人少，差异大 |
| 0.55 | 平衡（默认） | 一般场景 |
| 0.70 | 严格，容易拆分同人 | 说话人多，声音相似 |

### 3.4 与 step5 SpeakerBaseline 的衔接

```python
# step0: 聚类
clusterer = SpeakerClusterer(threshold=0.55)
speaker_ids = clusterer.fit_predict(audio_segments, sr)
# → ["speaker_0", "speaker_0", "speaker_1", "speaker_0", ...]

# step5: 个体基线
baseline = SpeakerBaseline()
for i, (a, e) in enumerate(zip(arousal, exertion)):
    sid = speaker_ids[i]
    result = baseline.normalize(sid, a, e)
    baseline.update(sid, a, e)
```

## 四、已知限制

1. **短段质量差**——< 0.5s 的段 embedding 不稳定，建议跳过
2. **同性别相似声音**——两个男声可能被合并为一组，需调高阈值
3. **噪声影响**——未降噪的段会影响 embedding 质量，建议 step1 降噪后再提取
4. **无监督聚类无 ground truth**——无法验证聚类是否正确，需人工抽查
