# 前置处理层 — 模块设计文档

> 对应系统架构第 2 层：音频预处理，为特征提取准备干净的目标语音
> 版本：v1.0 | 日期：2026-07-15

---

## 一、流程概览

```
原始音频（任意采样率，混含管制员+飞行员）
    │
    ▼
┌─────────────────────────────┐
│ ⓪ 重采样到 16kHz            │  统一内部格式
│   输入: 任意 sr 的 wav       │
│   输出: 16kHz mono wav      │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ ① ClearerVoice 降噪        │  MossFormerGAN_SE_16K，去环境噪声
│   输入: 16kHz wav           │
│   输出: 降噪后 16kHz wav    │
└──────────────┬──────────────┘
               │ audio_denoised
               ▼
┌─────────────────────────────┐
│ ② Silero VAD 语音活动检测   │  切分有效语音段
│   输入: 降噪后 wav           │
│   输出: [(start_sec, end_sec), ...] 语音段列表
└──────────────┬──────────────┘
               │ segments = [(0.5, 3.2), (5.1, 8.7), ...]
               ▼
┌─────────────────────────────┐
│ ③ ClearerVoice TSE 目标提取 │  从混合段提取管制员语音
│   输入: 混合段 + 参考语音    │  TSE 纯音频模型仅支持 8kHz
│   内部: 16kHz 降采样→8kHz   │  → 提取后升采样回 16kHz
│   输出: 每个段 → 目标语音    │
└──────────────┬──────────────┘
               │ target_segments = [audio_seg1, audio_seg2, ...]
               ▼
            产出：按时间排列的纯净管制员语音段
            → 喂给 openSMILE 做特征提取
```

## 二、各模块详细设计

### 2.0 重采样（8kHz→16kHz 兼容）

| 项目 | 内容 |
|------|------|
| 作用 | 将任意采样率统一到 16kHz（FRCRN_SE_16K 要求） |
| 输入 | 任意采样率 WAV |
| 输出 | 16kHz mono int16/float32 WAV |
| 方法 | `librosa.resample()` 或 `scipy.signal.resample()` |

**为什么 FRCRN 只支持 16kHz**：
- 已实测确认：FRCRN_SE_16K 不支持自动重采样，输入采样率 ≠ 16kHz 会报错
- ModelScope 文档明确："模型输入和输出均为 16kHz 单声道时域波形信号"

**8kHz→16kHz 重采样对降噪的影响（关键分析）**：
- VHF 电台的语音频带 0~3.4kHz，8kHz 采样率满足 Nyquist
- 升采样到 16kHz 后，高频段（4~8kHz）全是零能量，**不会引入噪声**
- FRCRN 在 STFT 频谱上做复数域掩码——对每个时频 bin 预测增益
  - 0~4kHz 的 normal 语音频谱 → 正常被增强
  - 4~8kHz 的零能量 bins → FRCRN 预测增益趋零，不引入伪影
- **结论：8kHz→16kHz→降噪→保持16kHz 是安全路径，不会二次引入噪声**

**openSMILE 后续兼容**：
- 降噪后保持 16kHz 给 openSMILE，比 8kHz 精度更高（F0/jitter 检测在 16kHz 上更准）
- 不需要降回 8kHz

**TSE 采样率衔接（二期）**：
- ClearerVoice 纯音频 TSE 仅支持 8kHz（不含视频的参考语音提取模型只有 8kHz 版本）
- 16kHz 的 TSE 模型全部需要视频（人脸/姿态）或 EEG 输入，不适用于管制场景
- 二期衔接时需在 TSE 前后加一次重采样桥接：16kHz→8kHz→TSE→16kHz
- 对 VHF 窄带语音无损：电台有效频带 0~3.4kHz，8kHz 采样率已覆盖；16kHz 高频段(4-8kHz)本无有效信息

### 2.1 ClearerVoice 降噪

| 项目 | 内容 |
|------|------|
| 模型 | `MossFormerGAN_SE_16K`（16kHz，GAN生成式增强，复杂噪声鲁棒） |
| 输入 | `numpy.ndarray` shape=(n,)，float32，16kHz 单声道 |
| 输出 | `numpy.ndarray` 同 shape、同采样率，降噪后 |
| 处理方式 | 整段音频一次输入（MVP离线），二期可切帧实时流式 |
| 错误处理 | 输入采样率 ≠ 16kHz → 自动重采样；静音段 → 原样返回 |

**为什么选 MossFormerGAN_SE_16K 而非 FRCRN**：
- MossFormerGAN 噪音消除更彻底（SSNR 14.03 vs 7.60 dB），语音自然度更高（4.4 vs 4.1，主观评分），对突发+复杂噪声鲁棒更强
- 更适合"ASR/特征提取前端预处理"场景——降噪后语音几乎无处理痕迹，不干扰 F0/jitter 检测
- MVP 离线处理，速度优先级低于质量，直接选用最佳模型

**边界情况**：
- 纯静音输入 → 原样返回，标记"静音"
- 极短音频（< 0.5s） → 跳过降噪，直接透传（降噪帧长不够）

### 2.2 Silero VAD 语音活动检测

| 项目 | 内容 |
|------|------|
| 模型 | `silero-vad`（ONNX，轻量，CPU实时） |
| 输入 | 降噪后音频 + 采样率 |
| 输出 | `list[dict]`，每项 `{"start": float, "end": float}`（秒） |
| 参数 | 采样窗口=30ms，静音阈值=0.5，最小语音段=0.3s，最小静音间隔=0.2s |
| 处理方式 | 滑窗逐帧判 speech/silence，合并相邻语音帧 |

**输出示例**：
```python
[
    {"start": 0.52, "end": 3.18},   # 管制员说"东方1234，推出批准"
    {"start": 5.14, "end": 7.85},   # 管制员说"联系地面121.9"
    {"start": 12.20, "end": 14.50}, # ...
]
```

**参数调优理由**：
- `最小语音段=0.3s`：管制指令最短约 0.5s（"推出批准"），0.3s 覆盖边界
- `最小静音间隔=0.2s`：避免把"s 尾音→停顿→下一句"拆成两段（电台 click 声可能被 VAD 误判为语音 start）

**边界情况**：
- 全静音 → 返回空列表 `[]`，标记"无效录音"
- 连续多人说话 → VAD 会给一个连续段，需 TSE 后续分离

### 2.3 TSE 目标说话人提取

| 项目 | 内容 |
|------|------|
| 模型 | ClearerVoice 纯音频 TSE（8kHz，基于参考语音的说话人提取） |
| 输入 | (1) 混合音频段 8kHz (2) 参考语音 8kHz（目标管制员 3-5s 干净样本） |
| 输出 | 目标说话人纯净语音 8kHz，提取后升采样回 16kHz 给 openSMILE |
| 采样率桥接 | 16kHz 降噪输出 → 降采样 8kHz → TSE 提取 → 升采样 16kHz |
| 参考语音来源 | 二期采集每个管制员 3-5s 安静环境录音，建库（也需保存为 8kHz） |
| MVP 阶段 | **暂不上**——公开数据集单说话人，VAD 切分后直接使用 |

**为什么 TSE 用 8kHz**：
- ClearerVoice 的纯音频 TSE 模型仅支持 8kHz（Audio-only Speaker Extraction, Reference Speech 子任务）
- 16kHz 的 TSE 模型（AV_MossFormer2_TSE_16K）全部需要额外的视觉/EEG 输入，管制场景不可用
- 对 VHF 电台无损失：有效语音带宽 0~3.4kHz，8kHz 采样完全覆盖；降噪后的 16kHz 信号降采样到 8kHz 丢掉的 4-8kHz 频段本就是空白的

**TSE 在链路中的角色**（v1.2 设计）：

```
VAD 切出语音段段
    │
    ▼
┌──────────────────────────┐
│ 这段是谁说的？            │  ← 二期用 TSE + 参考语音判断
│   → 管制员 → 保留         │
│   → 飞行员 → 丢弃         │
│   → 多人同时 → TSE 提取   │
└──────────────────────────┘
    │
    ▼
 纯净管制员语音段 → openSMILE
```

**MVP 跳过 TSE 的原因**：
- 公开数据集（RECOLA/RAVDESS）是单说话人录音，不存在飞行员/串扰
- MVP 用数据集自带说话人标签代替 TSE 判断
- TSE 的验证属于二期（需要真实空管+飞行员混合录音）

**二期 TSE 集成要点**：
- 参考语音库结构：`ref_speakers/{管制员ID}.wav`
- TSE 提取后，可选跑 ECAPA-TDNN 做身份校验（确认提取结果确为目标管制员）
- TSE 提取失败的段（置信度低）标记"存疑"，不喂给 openSMILE

## 三、数据流契约

### 3.1 模块间传递格式

```
Step 1 → Step 2:  numpy array (n_samples,) float32 16kHz
Step 2 → Step 3:  list[dict] + numpy array（段列表 + 完整音频引用）
Step 3 → 特征层:   list[numpy array]（按时间排列的纯净语音段）
```

### 3.2 元数据附带

每个语音段携带以下元数据：

```python
{
    "segment_id": "REC-1_seg_003",
    "start_sec": 12.20,
    "end_sec": 14.50,
    "duration_sec": 2.30,
    "speaker_label": "ATC_01",      # MVP用数据集标签，二期用TSE判定
    "confidence": 0.95,             # TSE提取置信度，MVP为1.0
    "quality_flag": "ok"            # ok / low_snr / uncertain
}
```

### 3.3 质量门控规则

经过降噪和 VAD 后，每个段做一次质量评估：

| 条件 | 标记 | 处理 |
|------|------|------|
| SNR > 阈值 且 VAD 置信 > 0.8 | `ok` | 正常喂特征提取 |
| SNR < 阈值 | `low_snr` | 降权或丢弃（REC-4教训） |
| 段长 < 0.3s | `too_short` | 丢弃（不足以提取可靠特征） |
| TSE 置信 < 0.6 | `uncertain` | 标记后保留，降低融合权重 |

```
project/
├── preprocess/
│   ├── __init__.py
│   ├── denoise.py            # ① ClearerVoice 降噪
│   ├── vad.py                # ② Silero VAD
│   ├── tse.py                # ③ TSE 目标提取（二期）

│   └── quality.py            # 质量门控

│   ├── ATC_001.wav

    ├── raw/                  # 原始音频
    └── processed/            # 降噪+VAD后的段
```

### pipeline.py 主入口接口

```python
def process_audio(
    audio_path: str,
    ref_speaker_path: str = None,  # MVP 为 None
    use_tse: bool = False          # MVP 为 False
) -> List[AudioSegment]:
    """
    返回按时间排列的纯净语音段列表
    """
    # 0. 加载 + 重采样到 16kHz
    audio = load_wav(audio_path, target_sr=16000)

    # 1. 降噪（MossFormerGAN_SE_16K，主模型；可降级 FRCRN）
    audio = denoise(audio)

    # 2. VAD 切分
    segments = vad_detect(audio)

    # 3. TSE（可选）
    if use_tse and ref_speaker_path:
        segments = tse_extract(segments, ref_speaker_path)

    # 4. 质量门控
    segments = quality_filter(segments)

    return segments
```

## 五、关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 内部统一 16kHz | ✅ | FRCRN 强制要求 16kHz；openSMILE 在 16kHz 上更准；8kHz 升采样不引入伪影 |
| 重采样在降噪之前 | ✅ | 先统一到 16kHz 再降噪，避免降噪后二次重采样损失 |
| 降噪在 VAD 之前 | ✅ | 噪声会影响 VAD 判 speech/silence，先降噪 VAD 更准 |
| 降噪后保持 16kHz | ✅ | 直接给 openSMILE，不降回 8kHz |
| VAD 在 TSE 之前 | ✅ | 先切段再提取，避免 TSE 处理长静音浪费算力 |
| 整段降噪而非逐段 | MVP 整段 | 离线处理，整段降噪效果更稳定，二期再考虑流式 |
| MVP 不上 TSE | ✅ | 公开数据集单说话人，无分离需求；TSE 留二期 |
| 二期 TSE 用 8kHz 桥接 | ✅ | 纯音频 TSE 仅 8kHz；降噪16k→降采样8k→TSE→升采样16k→openSMILE；VHF窄带无损 |
